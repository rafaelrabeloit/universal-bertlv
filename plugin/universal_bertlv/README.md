# Universal BERTLV

`universal_bertlv` is the Flutter-facing API for parsing and explaining EMV BER-TLV data.

It uses the endorsed `universal_bertlv_web` implementation on Web and
`universal_bertlv_mobile` on Android and iOS.

```dart
import 'package:universal_bertlv/universal_bertlv.dart';
```

See the project repository for examples and platform setup:
https://github.com/rafaelrabeloit/universal-bertlv
