# Universal BERTLV Mobile

Android and iOS implementation for the `universal_bertlv` federated Flutter
plugin. It calls the Kotlin/Native Universal BERTLV library through `dart:ffi`.

This package is selected automatically by `universal_bertlv`; applications
normally depend on the app-facing package rather than this implementation.

See the project repository for examples and platform setup:
https://github.com/rafaelrabeloit/universal-bertlv
